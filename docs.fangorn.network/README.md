# docs.fangorn.network

The Fangorn docs, built with Docusaurus. Pages are in `docs/`, the landing page is
`src/pages/index.tsx`, and the palette in `src/css/custom.css` follows fangorn.network's.
Diagrams are Mermaid code blocks.

```bash
npm install
npm start        # dev server
npm run build    # fails on broken links
```
